# Blog Website

A responsive multi-page blog website built with HTML5, CSS3, and Bootstrap 5.3.

# Live Demo

https://ismailturkoglu.github.io/awesome-blog-practice/

## Features

- Responsive navbar
- Hero section with hover animation
- Responsive blog cards
- Blog listing page with categories
- Pagination component
- Contact form UI
- Embedded Google Maps
- Mobile-friendly design
- Bootstrap 5.3 components
- Font Awesome icons

---

## Installation

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Open the project folder.

3. Run `index.html` in your browser.

## Responsive Design Notes

- Uses `rem` units for responsive typography
- Navbar adapts on mobile devices
- Responsive blog card layouts
- Images use `object-fit: cover`
